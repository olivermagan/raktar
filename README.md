# Raktár – készletkezelő

Telefonról használható raktárkezelő: élő kamerás vonalkód-olvasás, termékek képpel és méretekkel, vevők kedvezménnyel, rendelésfelvétel azonnali készletlevonással, bizonylat nyomtatás / e-mail.

- `index.html` – maga az app (GitHub Pagesen fut)
- `supabase-setup.sql` – adatbázis beállítás (Supabase → SQL Editor)

Első indítás: Beállítások → Supabase Project URL + publishable key → bejelentkezés.
